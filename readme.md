# C++ Inventory Management System

A simple Inventory Management System developed using C++.

## Features

- Add new inventory items
- Display all inventory items
- Search items using Item ID
- Modify existing item details
- Delete inventory records
- Store and retrieve data using file handling

## Technologies Used

- C++
- OOP (Object-Oriented Programming)
- File Handling
- STL

## Concepts Used

- Classes and Objects
- Constructors
- Member Functions
- File Handling
- Binary Files
- `fstream`
- `seekg()` and `seekp()`
- Searching, modifying and deleting records

## How to Run

1. Clone or download this repository.
2. Open the project in VS Code.
3. Compile `project1.cpp` using a C++ compiler.
4. Run the generated executable.

## Purpose

This project was created to practice C++ programming, Object-Oriented Programming and file handling by building a basic inventory management system.
